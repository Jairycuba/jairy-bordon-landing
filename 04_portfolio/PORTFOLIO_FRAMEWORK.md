# Portfolio Framework

## Positioning rule

Every project must be described truthfully as a personal project, demo, prototype, internal tool or product. Do not present personal work as paid client work unless that is true.

## Initial project categories

### Web and business systems

Applications that organize workflows, forms, bookings, dashboards, administration and customer operations.

### Trading and market software

LifeOptions-related tools, trading intelligence, options workflows and MoomooBeast. Present these as software projects that demonstrate technical depth, not as the central definition of the Jairy Bordon brand.

### Automation, agents and integrations

MCP integrations, agent-based systems and tools that connect data, workflows and services.
